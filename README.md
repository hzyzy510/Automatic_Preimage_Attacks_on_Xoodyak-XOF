This code implements preimage attacks on Xoodyak-XOF using the linear structure method.

- The `code` folder contains the attack code for different numbers of rounds.
- `xoodyak_y2_linearization.py` is used to determine the minimum number of variables that need to be guessed for linearizing the conditions.
- The `dependency` folder contains the dependency relationships of the attack structure conditions for different numbers of rounds.
- The `result` folder contains schematic diagrams of the structures searched by the weight-adaptive structure search algorithm for different numbers of rounds.
